# АгроМаркет (React)

Лабораторная работа №3: React, props, state, hooks.

Запуск: `npm install`, затем в одном терминале `npm run server` (json-server на порту 3001), в другом `npm run dev`.
## Лабораторная 4 — вёрстка

### Box model карточки (часть 1)
content: ... px, padding: 16px, border: 1px, margin: 0. С box-sizing: border-box ширина стала равна заданной, потому что padding и border входят в неё, и карточка не раздувается.

### repeat(4, 1fr) на узком экране (часть 4)
Колонок остаётся четыре, поэтому карточки сжимаются в узкие полосы, текст и кнопки ломаются.

### auto-fit vs auto-fill (часть 4)
auto-fit растягивает оставшиеся карточки на всю ширину, а auto-fill сохраняет пустые колонки, и карточки остаются узкими.
